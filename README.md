Blue Server
A high-performance game server built with .NET 10, featuring a scalable API server and optimized TCP game server architecture.
🎮 Project Overview
Blue Server is a comprehensive game backend solution combining a RESTful API server for account management and a custom TCP game server for real-time multiplayer interactions. The project implements industry-standard patterns for session management, packet handling, and player authentication.
Current Progress: 85% (MVP implementation complete)
📋 Tech Stack
Backend Infrastructure

Framework: .NET 10
ORM: Entity Framework Core
Database: PostgreSQL
Cache: Redis
Authentication: JWT + BCrypt
Communication: TCP/Custom Packet Protocol
